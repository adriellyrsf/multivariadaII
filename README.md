# Perfis educacionais e socioeconômicos dos municípios nordestinos: Uma análise com Componentes Principais e Cluster

Trabalho da disciplina de Multivariada II (2026.1) - Estatística / UEPB.

[Acesse o Relatório Completo Aqui](https://adriellyrsf.github.io/multivariadaII/)

---

### Sobre o Projeto
Estudo focado na caracterização e agrupamento dos 1.724 municípios do Nordeste a partir de indicadores do Atlas do Desenvolvimento Humano e do IDEB. A análise utilizou Análise de Componentes Principais (ACP) para redução de dimensionalidade e Análise de Cluster para identificação de perfis regionais semelhantes.
